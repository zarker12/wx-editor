公众号订阅管理

添加 WeWe RSS / Wechat2RSS / RSSHub 输出的 RSS/Atom 链接，保存后可一键同步文章。部署到 Cloudflare 后由 Cron 每 2 小时自动同步。

如何获取公众号 RSS 链接？（点击展开教程）
方案 1：WeWe RSS（最稳定，推荐，免费开源）
基于微信读书接口，目前最稳定的公众号 RSS 方案，GitHub 6500+ star。
方式 A：Docker Compose 一键部署（推荐）
① 新建 docker-compose.yml，内容：
version: '3.9'
services:
  wewe-rss:
    image: cooderl/wewe-rss:latest
    ports: ["4000:4000"]
    environment:
      DATABASE_URL: "file:/app/data/wewe-rss.db"
      DATABASE_TYPE: "sqlite"
      AUTH_CODE: "你的授权码"
    volumes: ["./data:/app/data"]
② 运行 docker-compose up -d
方式 B：SQLite 单镜像（更简单）
直接运行：
docker run -d --name wewe-rss -p 4000:4000 \
  -e DATABASE_TYPE=sqlite -e AUTH_CODE=123567 \
  -v $(pwd)/data:/app/data cooderl/wewe-rss-sqlite:latest
方式 C：免费云平台免服务器部署
Railway / Zeabur / Hugging Face 一键部署模板，参考 github.com/cooderl/wewe-rss
部署后三步拿链接：
1. 浏览器访问 http://你的IP:4000 → 用 AUTH_CODE 登录
2. 「账号管理」→ 微信扫码登录微信读书（别勾"24小时后自动退出"）
3. 「公众号源」→ 添加 → 粘贴公众号文章链接 → 复制 RSS（形如 http://你的IP:4000/feeds/MP_WXS_xxxx.atom）
方案 2：Wechat2RSS（300+公众号已收录，免部署）
开源公益项目，已收录 300+ 热门公众号，24 小时内更新。
① 打开 wechat2rss.xlab.app/list
② 搜索你想订阅的公众号
③ 复制对应 RSS 链接（形如 https://wechat2rss.xlab.app/feed/xxx.xml）
完全免费，无需部署。若想订阅未收录的公众号需用方案 1。
方案 3：RSSHub 自建（支持公众号热榜）
开源 RSS 生成器，可同时做公众号 RSS 与爆文榜单数据源。
① 部署：docker run -d -p 1200:1200 diygod/rsshub
② 访问 http://localhost:1200
③ 链接格式：http://你的IP:1200/wechat/公众号id
公共实例 https://rsshub.app 可临时测试但不稳定。
方案 4：直接粘贴任意 RSS 链接
如果你已有公众号的 RSS/Atom 链接（任何来源），直接填到下方「RSS/Atom 链接」框即可，系统会自动识别 RSS 2.0 与 Atom 两种格式。
添加后做什么？
填好「公众号名称」+「RSS 链接」→ 点「添加」→ 点下方「立即同步所有订阅」抓取文章。
部署到 Cloudflare 后，Cron 每 2 小时会自动同步，无需手动刷新。
