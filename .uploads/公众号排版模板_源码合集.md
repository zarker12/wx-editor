# 公众号排版模板 · 6 主题 HTML 源码合集

> 本文档包含 6 套公众号排版模板的完整 HTML 源码。每套都是带内联样式的 `<section>` 片段，无外部依赖，可直接粘贴到微信公众号编辑器。

## 设计约束（Trae Code 实现时必须遵守）

- **所有样式必须内联**（`style` 属性），不能用 `<style>` 标签、CSS class、外部 CSS——公众号编辑器会过滤掉

- **所有文字节点必须用 `<span leaf="">文字</span>` 包裹**——否则粘贴到公众号后样式会大面积丢失

- 禁用 `<div>`/`<script>`/`position:fixed|absolute|sticky`/`float`/`@media`/`@keyframes`/`display:grid`/CSS 变量

- 可用：内联 `style`、`display:flex`（有限）、`linear-gradient`、`border-radius`、`box-shadow`、`<section>/<p>/<span>/<strong>/<img>/<h3>`

- **6 个主题的尾部 intro 卡片结构统一**（圆头像 + 作者名 + 简介 + 三点分隔 + 关注/产出 + 互动 + 免责），只是配色和细节装饰随主题变化

- 正文关键词用主题色下划线标记（每段 1-3 处）
